# 個人財務儀表板

以繁體中文顯示個人資產、負債、現金流、投資槓桿及市場壓力測試。純 HTML、CSS、JavaScript，無套件、無登入、無資料庫、無付費 API。

## 開啟方式

最簡單：下載單檔版 `dashboard.html`，用瀏覽器開啟即可。它已包含所有樣式與計算程式，不需要其他檔案。

開發版則使用 `index.html`、`style.css`、`app.js` 三個檔案，請放在同一個資料夾。

GitHub 下載整個專案：儲存庫頁面 → Code → Download ZIP → 解壓縮。

若要在開發環境使用固定網址，在這個資料夾執行：

```sh
python -m http.server 8000 --bind 0.0.0.0
```

接著在自己的電腦瀏覽器開啟 `http://localhost:8000`。這是本機開發網址，不是已公開的網站。停止伺服器可按 Ctrl+C。

不需要安裝任何依賴或執行建置。

## 主要檔案

- `dashboard.html`：可獨立使用的完整單檔版本；修改開發版後須重新產生。
- `index.html`：畫面結構、表單、KPI 與結果區。
- `style.css`：顏色、間距、桌面與手機版面。
- `app.js`：計算、輸入檢查與自動儲存。

## 資料與計算

第一次開啟金額為 0，槓桿 ETF 倍率為 2。輸入有效數字後會立即計算並儲存在目前瀏覽器的 localStorage。資料不會上傳，亦不會跨裝置同步。若瀏覽器禁止儲存，畫面會顯示警示。金額單位為新台幣，最高接受 1,000,000,000,000,000；ETF 倍率至少為 1，不涵蓋反向 ETF。空白金額視為 0，空白倍率視為 2。

「股票 / ETF 市值」自動加總一般投資與槓桿 ETF，避免重複計算。投資用途信貸是信貸餘額的一部分，不會另外加進總負債；不能超過信貸餘額。輸入有誤時，結果與儲存資料保留在上一筆有效狀態。

- 總資產 = 現金 + 一般投資 + 槓桿 ETF + 房屋估值 + 其他資產。
- 總負債 = 房貸餘額 + 信貸餘額。
- 淨資產 = 總資產 − 總負債。
- 金融資產 = 現金 + 投資總市值（其他資產不預設為金融資產）。
- 負債 / 資產比例 = 總負債 ÷ 總資產。
- 每月債務還款占比 =（每月房貸還款 + 每月信貸還款）÷（年收入 ÷ 12）。
- 現金支撐月數 = 現金 ÷（生活支出 + 房貸還款 + 信貸還款），不含固定投資。
- 每月結餘 = 年收入 ÷ 12 − 生活支出 − 債務還款 − 固定投資。
- 投資總市值 = 一般投資 + 槓桿 ETF。
- 等效市場曝險 = 一般投資 + 槓桿 ETF × 倍率。
- 內含曝險倍數 = 等效市場曝險 ÷ 投資總市值。
- 投資用途負債占比 = 投資用途信貸 ÷ 投資總市值。
- 綜合市場槓桿 = 等效市場曝險 ÷（投資總市值 − 投資用途信貸）。

分母為 0 時顯示「—」；投資淨值為負數時，綜合市場槓桿也顯示「—」。金額顯示四捨五入至整數，比例與倍數最多兩位小數，計算使用未四捨五入數值。

壓力測試將一般投資乘以（1 − 跌幅），槓桿 ETF 乘以 max(0, 1 − 倍率 × 跌幅)。再扣除投資用途信貸得到投資淨值；整體淨資產只調整投資市值變化。其他資產與負債保持不變。不考慮每日重設、波動耗損、利息或交易成本，不代表槓桿 ETF 長期實際報酬。

## 資料保存注意事項

請固定使用同一個瀏覽器及開啟方式。同一檔案直接開啟與透過伺服器開啟，可能使用不同的儲存區；不同網址或埠號也不共享資料。直接開啟檔案的 localStorage 支援依瀏覽器而異，建議以固定網址使用。清除瀏覽器資料、使用無痕模式或換裝置可能失去紀錄。

清除全部資料前會要求確認。此操作只重設這個應用程式的資料。

## 首頁提醒

首頁僅顯示淨資產、金融資產、現金緩衝月數與綜合市場槓桿。其他明細位於下方，輸入表單預設收合。提醒門檻可在畫面底部展開查看：現金未滿 3 個月為紅、未滿 6 個月為黃；綜合槓桿超過 2x 為紅、超過 1.5x 為黃；負債比超過 70% 為紅、超過 50% 為黃；還款比超過 50% 為紅、超過 30% 為黃。這些是固定參考門檻，非個人化建議。正常數字不特別標色。

## 財務目標

首頁四個 KPI 下方可輸入目前年齡、目標年齡、目標金融資產、每月固定投入與預期年化報酬率。每月固定投入沿用現金流中的固定投資金額，不另外相加或重複扣款。舊有儲存資料會保留，新增目標欄位預設為 0；目標金額為 0 時顯示設定提示。

設目前金融資產為 P，每月底投入為 C，剩餘月數 n =（目標年齡 − 目前年齡）× 12，月報酬率 r = (1 + 年化報酬率 / 100)^(1/12) − 1。預估資產 = P × (1+r)^n + C × ((1+r)^n − 1) / r；r = 0 時為 P + C × n。目前完成率為目前金融資產 / 目標金融資產，可超過 100%。需增加的月投入依同一公式反推，最低為 0，無條件進位至整數新台幣。若剩餘期間為 0 且資產不足，會提示延後目標年齡。

年齡接受 0 至 120 的整歲，年化報酬率接受 -99% 至 100%，支援負報酬。假設現金及全部投資適用同一報酬率，不含通膨、稅費或提領，並非保證報酬。目標設定與原有財務資料一同儲存在瀏覽器。
