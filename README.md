# 個人財務儀表板

繁體中文、免費、免登入的個人財務工具。首頁保留淨資產、金融資產、現金緩衝月數及綜合市場槓桿四個 KPI；其他功能放在下方，備份與歷史區塊預設收合。純 HTML / CSS / JavaScript，沒有套件、帳號、資料庫、追蹤或廣告 SDK。

## 使用方式

建議使用固定 HTTPS 網址（例如 GitHub Pages）。網站載入的只有公開程式碼；你的財務資料不會提交給網站。

下載時可直接開啟 `dashboard.html`（完整單檔版）。但 `file://` 網頁的 localStorage 保存行為依瀏覽器而異，不保證關閉後保留，頁面會提醒。請先匯出 JSON，再搬到固定網址使用。

開發時，在專案資料夾執行：

```sh
python -m http.server 8000 --bind 0.0.0.0
```

於自己的電腦瀏覽器開啟 `http://localhost:8000`。不需要安裝依賴或建置。不要依賴不同網址、埠號、瀏覽器或裝置共用資料。

## 資料保存與備份

頁面顯示：

> 所有財務資料僅儲存在此裝置瀏覽器，不會上傳至伺服器。
>
> 清除瀏覽器資料、更換裝置或使用無痕模式可能造成資料遺失，建議定期匯出備份。

- 每次修改即同步寫入 localStorage，不等到關閉頁面才儲存。重新整理、關閉分頁或正常結束瀏覽器後，在同一網址及瀏覽器恢復。
- 顯示「資料已儲存」及最後成功儲存的時間。被禁止儲存或空間不足時，明顯顯示錯誤；不把失敗時間當成成功時間。
- 尚未通過檢查的輸入也會以草稿保存。計算維持上一筆有效資料，重新開啟會恢復草稿並要求修正。
- 「警戒線與資料備份」內可匯出 / 匯入 JSON。完整備份包含有效財務輸入、未完成草稿、財務目標、警戒線、快照及儲存時間；備份檔含敏感資料，請自己妥善保存。
- 匯入先驗證格式、數值、日期及版本，再要求確認，才取代資料。匯入後最後儲存時間更新為本次還原時間。
- 「清除本機資料」需要連續兩次確認，重設本工具的資料及快照，不清除其他網站資料。建議先匯出備份。
- 支援舊版 v1 資料及備份，新增欄位以預設值補齊，不丟棄舊版原始紀錄；主動清除資料時才清除舊版 key。
- 相同裝置同一瀏覽器的所有使用者共用這份資料。若家人共用一台電腦，請使用各自的瀏覽器使用者設定檔。不同裝置間不自動同步，需手動匯出 / 匯入。
- 瀏覽器設定為離開時清除資料、私密瀏覽、儲存權限不足或系統回收網站儲存空間，仍可能丟失資料；本網站無法覆寫瀏覽器政策。

網頁沒有 fetch、XHR、Beacon、遠端字型、第三方程式或分析工具。CSP 的 `connect-src 'none'` 和 `form-action 'none'` 進一步禁止程式網路連線與表單提交；只有取得靜態網頁資源的 GET 請求，沒有包含財務輸入的上傳。

## GitHub Pages 部署

1. 在 GitHub 開啟 `damx2002/personal-finance-dashboard`。
2. 進入 **Settings → Pages**。
3. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
4. Branch 選 **main**，資料夾選 **/(root)**，按 **Save**。
5. 等 GitHub 顯示部署成功，再使用 Pages 頁面提供的網址。

若 GitHub 方案不支援私有儲存庫的 Pages，需改用支援的方案或公開儲存庫；不要把 JSON 財務備份加入 GitHub。

預期網址：`https://damx2002.github.io/personal-finance-dashboard/`。這是部署後的位置，不表示目前已發布成功。`.nojekyll` 讓這份靜態網頁直接部署，不需要框架。所有資源採相對路徑，可以在專案子路徑使用。

GitHub Pages 是一般 HTTPS 靜態網站，localStorage 綁定其 origin；Pages 更新程式碼不會主動刪除使用者資料。改用自訂網域或不同 origin 時，必須在舊網址先匯出，再於新網址匯入。

### 部署後驗收

使用正常模式（非無痕）開啟固定 Pages 網址，輸入一筆測試資料，檢查已儲存與時間。重新整理，再關掉瀏覽器重開同一網址，確認保留。匯出備份、確認兩次清除、匯入備份並確認還原。開發者工具 Network 中，輸入、保存、匯出、匯入及快照操作都不應送出網路請求。

自動測試已模擬 `/personal-finance-dashboard/` 子路徑；真實 Pages 的發布狀態、HTTPS 網址及瀏覽器政策，仍需在部署後實測。執行環境可能無法連到 github.io，不能把這種網路限制當成網站部署失敗。

## 計算

股票 / ETF 資產自動加總一般股票及槓桿 ETF，不重複輸入。投資用途信貸是信貸餘額的一部分，不能超過信貸餘額。

- 總資產 = 現金 + 一般投資 + 槓桿 ETF + 房屋估值 + 其他資產。
- 總負債 = 房貸餘額 + 信貸餘額；淨資產 = 總資產 − 總負債。
- 金融資產 = 現金 + 投資總市值；不將其他資產預設為金融資產。
- 還款比 =（每月房貸 + 信貸還款）÷（年收入 ÷ 12）。
- 現金緩衝月數 = 現金 ÷（生活支出 + 房貸還款 + 信貸還款），不含固定投資。
- 每月結餘 = 年收入 ÷ 12 − 生活支出 − 債務還款 − 固定投資。
- 等效市場曝險 = 一般投資 + 槓桿 ETF × 倍率。
- 投資內含曝險倍數 = 等效曝險 ÷ 投資市值。
- 綜合市場槓桿 = 等效曝險 ÷（投資市值 − 投資用途信貸）。

分母為零時顯示「—」，投資淨值不大於零時槓桿也顯示「—」。金額四捨五入至整數，比例和倍數最多兩位小數，計算使用原始數值。

### 自訂警戒線

預設最低現金緩衝 6 個月、最高還款比 40%、最高綜合槓桿 2x，可自行修改並備份。現金低於最低值為紅色，門檻至 1.2 倍為黃色；還款比或槓桿高於最高值為紅色，門檻的 80% 至 100% 為黃色。其餘正常顯示。負淨資產、負月結餘、投資淨值無效及有債務無收入等狀態仍會提醒，不額外替負債比設定未經使用者選擇的警戒值。

### 財務目標與情境

目前金融資產為 P、每月底投入為 C、剩餘月數 n = 年齡差 × 12、月報酬率 r = (1 + 年化報酬率 / 100)^(1/12) − 1。預估資產 = P × (1+r)^n + C × ((1+r)^n − 1) / r；r 為零時改為 P + C × n。反推每月追加投入，最低為零，進位至整數新台幣。無剩餘期間且不足時提示延後目標年齡。

「比較年化報酬情境」可展開查看保守 5%、基準 8%、積極 12%、自訂報酬各自的預估資產。現金與所有投資皆適用同一報酬假設，不含通膨、稅費及提領，非報酬保證。每月固定投入與現金流共用，不重複扣款。

### 壓力測試

一般投資 ×（1 − 跌幅），槓桿 ETF × max(0, 1 − 倍率 × 跌幅)，再扣除投資用途信貸。其他資產及負債不變。以同一分段線性模型求投資淨值歸零的最早跌幅。不是單純曝險比例，因 ETF 市值有零下限。這是簡化情境，不代表槓桿 ETF 長期報酬，未計每日重設、波動耗損、利息和成本。

### 每月快照

手動選日期儲存當時的淨資產、金融資產、投資市值、總負債及綜合槓桿。每月份一筆，取代前確認，最多 600 筆。歷史數值固定，不隨最新輸入變動。原生 SVG 折線圖可切換五項指標，槓桿無有效值時不連接該段；下方表格可讀取完整數字。

## 維護與測試

- `index.html`：表單及畫面。
- `style.css`：桌面與手機版面。
- `app.js`：計算、持久保存、備份及快照。
- `dashboard.html`：可獨立使用的完整單檔版。
- `scripts/build-single.py`：從上述三檔產生單檔版。
- `tests/browser.cjs`：瀏覽器測試，以獨立臨時設定檔實際關閉再啟動 Chromium，驗證保存、JSON 還原、確認取消、草稿、配額錯誤、手機版面及請求行為。

修改開發版後：

```sh
python scripts/build-single.py
node --check app.js
node tests/browser.cjs
```

測試需要開發機已安裝 Playwright 與 Chromium（使用者使用網頁不需要）。預設 `/usr/bin/chromium`，可透過 `CHROMIUM_PATH` 指定。沒有必要為應用安裝 Node 套件或建立鎖檔。

## 指標說明與財務摘要圖

現金緩衝月數、綜合槓桿、每月還款比、負債比及投資借款比旁有可展開的「查看說明」。說明使用目前有效數值及使用者自訂警戒線，列出差距與可優先檢視的方向；不把警戒值視為通用安全標準，也未新增負債比或投資借款比的任意門檻。

首頁按「產出財務摘要圖」，使用原生 Canvas 在本機產生 1080 × 1350 直式 PNG，並提供預覽及再次下載連結。內容包含八項主要指標、財務目標及大盤 -20% / -30% / -50% 的整體淨資產，檔名為 `財務摘要_YYYY-MM-DD.png`。只使用本機字型，沒有截圖套件、CDN、遠端字型、外部 API 或財務資料傳輸。PNG 不包含姓名、Email、帳號、銀行或個股名稱。

勾選「分享版隱藏金額，只顯示比例」後，舊預覽立即移除，必須重新產生；新版只顯示六項比例／月數／倍數，沒有任何金額。因原資料沒有獨立的淨資產目標，**淨資產完成率 = 淨資產 ÷ 目標金融資產**，圖中有註明；財務目標完成率仍為金融資產 ÷ 目標金融資產。未設定目標時不計完成率。

快照的「產出此月摘要圖」只使用該快照已記錄的資料。原快照結構沒有當時現金流、目標及壓力情境，因此缺項顯示「未記錄」；總資產由淨資產加總負債還原。**不混用目前財務輸入補寫歷史**，也沒有改動快照或備份結構。

頁面有上個日曆月快照時，顯示本月淨資產增減及百分比：有本月快照即使用本月快照，否則使用目前有效輸入並註明。上月淨資產不大於零時不計百分比；沒有上月快照就不顯示比較，不把跨月缺漏當成上月。此資訊不新增 KPI 卡片。

頁面與 PNG 會跟隨系統深色／淺色模式。分享圖片中包含敏感財務資料，請在分享前自行確認隱藏金額設定。

新增測試：`node tests/summary.cjs`，涵蓋桌面 Chromium 與 Pixel 7 / Android Chrome 模擬、兩種 HTML 版本、PNG 檔頭與尺寸、實際 Canvas 繪製文字、隱藏金額、歷史缺項、月比較、手機版面及無對外請求。已人工檢視產出的中文圖片；此環境沒有實體 Android 手機，實機下載與相簿保存仍需使用者確認。

金額輸入欄位下方會即時顯示千分位與約略萬／億元，例如輸入 `12000000` 顯示 `NT$ 12,000,000 · 約 1,200 萬元`。輸入框即時加入千分位逗號，保留手機數字鍵盤並維持游標位置；年齡、比率、月數與倍率不套用金額提示。此顯示不改變資料或備份格式；計算及 localStorage 仍儲存純數字，支援貼上含逗號的金額。
